# 缘之空 · 发售档案

按 CUFFS 官方历次贩售企划整理的《缘之空》相关商品档案。站点保留同一商品的再版、复刻和不同销售批次，并提供检索、筛选、排序、中文辅助翻译与人民币参考价。

## 在线部署

`outputs/yosuga-sales-preview/` 中的静态站点通过 GitHub Actions 自动发布到 GitHub Pages。推送到 `main` 分支后会触发部署。

## 数据说明

- 商品名称、说明、规格、价格、图片与销售批次来自 CUFFS/Sphere 官方页面。
- 本仓库仅作资料整理与检索；相关作品、插画和商品图片的权利归原权利人所有。
- 人民币金额仅为实时汇率参考，不构成购买报价。
